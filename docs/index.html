Why I built it

Use the research notes

  1. Clone the documentation repository.

    git clone https://github.com/Yashwanth-Kumar-26/myniat-reverse-engineering.git
cd myniat-reverse-engineering

  2. Read the public analysis in README.md and the live documentation page.

    Open the repository

  3. For your own authorized research, use jadx against an APK you are permitted to inspect.

    jadx -d out your-authorized-app.apk

  4. Record API, architecture, permissions, and security observations without publishing proprietary source or secrets.

Educational and research use only. The repository is not affiliated with or endorsed by NxtWave or MyNIAT.
